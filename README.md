## 🎨 Interfaces

<img src="https://skillicons.dev/icons?i=react,ts,vite,tailwind,nextjs" alt="React, TypeScript, Vite, Tailwind, Next.js" />

| Techno | Ce que j'en fais | Pourquoi |
|---|---|---|
| **React** | Les écrans de toutes mes apps | Des composants réutilisables que je partage d'un projet à l'autre |
| **TypeScript** | Tout mon code | Les types attrapent les erreurs tôt, très utile quand c'est l'IA qui écrit |
| **Vite** | Lancer et compiler l'interface | Rapide et simple à configurer |
| **Tailwind CSS** | Le style et l'identité visuelle | Des tokens de design partagés pour garder la même ambiance partout |
| **Next.js** | Mes sites et apps web | Pages, API et rendu serveur au même endroit |

## 🗄️ Données et back-end

<img src="https://skillicons.dev/icons?i=sqlite,prisma,nodejs,py" alt="SQLite, Prisma, Node.js, Python" />

| Techno | Ce que j'en fais | Pourquoi |
|---|---|---|
| **SQLite** | Stocker les données en local | Un seul fichier, aucun serveur à gérer : idéal pour des apps locales |
| **Prisma** | Parler à la base de données | Un schéma clair et des migrations automatiques |
| **Node.js** | Faire tourner le JavaScript hors du navigateur | Le même langage partout, du front au back |
| **Python** | Un bot Discord | Parfait pour les scripts et les bots |

## 🧫 Infra et homelab

<img src="https://skillicons.dev/icons?i=linux,windows,nginx" alt="Linux, Windows, Nginx" />&nbsp;
![Proxmox](https://img.shields.io/badge/Proxmox-E57000?style=for-the-badge&logo=proxmox&logoColor=white)
![Tailscale](https://img.shields.io/badge/Tailscale-242424?style=for-the-badge&logo=tailscale&logoColor=white)

| Techno | Ce que j'en fais | Pourquoi |
|---|---|---|
| **Proxmox** | Virtualiser mes serveurs | Plusieurs machines virtuelles sur un seul serveur |
| **Windows Server + Active Directory** | Gérer un domaine et ses utilisateurs | Apprendre l'infra d'entreprise en conditions réelles |
| **Tailscale** | Relier mes machines entre elles | Un réseau privé simple, sans ouvrir de ports |
| **Nginx** | Exposer mes services en HTTPS | Un point d'entrée propre et sécurisé |
